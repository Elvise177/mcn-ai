## 3. 逐条影响面

### B-1 检索整句必空 —— 唯一会动既有基线的一条

**方案（已拍板）**：两遍 AND→OR + 虚词清洗。

- AND 先跑；命中为空再用 OR 跑一遍并标「模糊匹配」；**两遍都空才是真·没找到**
- 查询侧清洗：去掉「的/是/什么/怎么样/多少」这类虚词
- **不用纯 OR**：OR 意味着任一 token 命中即返回，中文常用字随便一撞就有结果，
  H-11 那轮做的三态里的「没找到」从此几乎不可达。而**「没找到」是陷阱题防幻觉的地基**——
  拆了它，模型就再也分不清「我搜不到」和「库里没有」

**波及**：`vault:search` 是单一入口——知识库页搜索框、`search_knowledge` 工具、走查断言全走它。
改这里等于同时改了 UI 搜索与 AI 问库。

**会挂的既有断言**：

| 断言 | 为什么会挂 | 怎么调 |
|---|---|---|
| 05b 零命中态（生造词） | 生造词在 OR 遍下可能有结果 | 判据改成「两遍都空」 |
| M-13 「N / 共 M 条」计数对账 | 模糊匹配那遍的 total 口径要重新定义 | 计数需区分精确/模糊 |
| 05「有搜索词时左栏不许出现文件树叶子」 | 不受影响 | — |

**要新增的回归用例**（探针 5 组对照固化）：

| 查询 | 修前 | 修后要求 |
|---|---|---|
| `公司年度目标` | 0 | 有命中 |
| `谁的绩效最好` | 0 | 有命中 |
| `星母第二期` | 0 | 有命中 |
| `2026年上半年收支` | 0 | 有命中 |
| `完美日记` | 0 | **仍须为 0**（陷阱题地基，不许被模糊匹配救活） |

**风险**：中等偏低。纯本地逻辑、可离线验证、不烧 token。

## 5. 顺手核实项：出厂档位映射**是生效的**，不用修

`migrateTiers()` 的调用点在 `src/main/ipc.ts:33`（`registerIpc` 时执行），**早于任何登录与 provision**。
真机全新装：首启时 store 为空 → `vaultPath` 无、三把 key 全无 → 走「全新安装：档位映射用出厂值」
并置 `tierMigrated`。

阶段二那个隔离实例被判成老用户，是因为**首启之前手写了带 key 的 config**——环境造成的，不是产品缺陷。

**残留风险**：这个结论依赖「migrateTiers 早于 provision」这个顺序，而代码里没有任何东西保住它。
**走查补一条零成本断言**：全新 userData 启动后 `ai.tiers()` 的标准档必须是 `api.deepseek.com`、`overridden:false`。

## 5b. 线路纪律（2026-08-18 定，最高优先级，永久生效）

事故：测试隔离实例被 `migrateTiers` 判成老用户，标准档被搬到中转站，
**20 轮本该官方直连的测试调用打在中转站余额上**，把它打穿——而那把 key 与网页版共用。

**纪律三条**：

1. **DeepSeek（`deepseek-v4-pro` / `deepseek-v4-flash`）一律走官方直连 `api.deepseek.com`**，
   key 用官方平台账户那把（隔离实例里即 `encryptedLlmKey`）
2. **aihubmix 只允许 `claude-opus-5`（增强档）使用**，且**在修复全部落地前增强档测试一律冻结**
   （余额只留给生产）
3. **任何真实调用开跑前**：报预算 + 打印 `ai.tiers()` 实测 base URL；
   标准档不是 `api.deepseek.com` 就立刻停下报人

**执行点**：

| 位置 | 做法 |
|---|---|
| 测试隔离实例 config 预置 | 显式写 `tierMigrated: true` + `tierOverrides.standard` = 出厂映射；**增强档不给 key**（冻结靠环境保证，不靠自觉） |
| `e2e/walkthrough.mjs` | 主实例启动后 `assertStandardRoute()`，标准档非官方直连即走查失败。**唯一豁免**是 45e 那个故意走老用户分支的实例 |
| 批跑脚本 | 起跑前闸门：标准档非官方直连、或增强档仍有 key，直接抛错停跑 |

## 5d. Grep 敏感约束（已裁决）

第 0 批的提示词让模型在检索落空时转 `Grep/Read` 兜底，实测直接把它带进了达人信息表
（内含身份证/银行卡），回答里出现了达人真名。

**裁决**：**不限制读取**，但引用敏感文件时**只给结论与出处，不得复述个人字段**——
身份证、银行卡、联系方式、真实姓名一律不出现在回答里；**人名用艺名或姓氏+职务**。
写进第 0 批的系统提示词，与 B-3 同一条规则块。
