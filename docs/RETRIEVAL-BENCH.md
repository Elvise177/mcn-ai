> 尺子：`desktop/e2e/retrieval-bench/bench.jsonl`（45 题，标准答案由人读原文写）＋ `desktop/scripts/retrieval-bench.mjs`（`npm run bench:retrieval`，口径见 `desktop/e2e/retrieval-bench/README.md`）

口径（详见 README）：
- **召回命中率**：应命中文件里被摆到模型面前（`search_knowledge` 前 6 条 ∪ Read 过）的比例，按题平均；**全命中率**：应命中文件全部被摆到面前的题占比；**读到率**：应命中文件真的被 Read 的比例
- **要点覆盖率**：每条要点 covered 1 / partial 0.5 / missing 0，按题平均；**核心要点覆盖率**：只算每题前 2 条要点（问题直接问的那部分）。两者的差就是"答对了但没多讲"的部分
- **引用正确率**：回答里能解析到库内文件的 `[[引用]]` 中落在应命中集合内的比例（合并统计）。64 条引用里 63 条能解析到文件，产品自己标"存疑"的只有 2 条
- **陷阱题拒答率**：判分认为"明确说了库里没有"且"没有编造"的比例
- 判分模型 = 同一档 deepseek-v4-pro，temperature 0，每条要点附理由与从回答里逐字摘的证据

### 给客户报数时怎么说

- "问库里有的东西，93%（关键词 95% / 敏感区 100% / 语义 70% / 跨文档 68% 的加权）能把正确文件找出来；问库里没有的东西，5/5 明确说没有，不编"
- 要点覆盖率 63% **不能直接说成"准确率 63%"**：它把"少讲"算成了扣分。核心要点覆盖率 74% 更接近"问什么答什么"的准确率；引用正确率 70%（关键词题 100%）是"标的来源对不对"

## 2. 四类题各自的短板

| 题型 | 短板 | 现场 |
|---|---|---|
| ①关键词题 | 检索基本不丢（95%），丢分在**回答收得太短**：读到了对的文件，只答问题字面问的那两点，文档里紧挨着的机制/条件不带 | M-K5 问"几天、指定品"，两点全对但 4 条要点覆盖 38%；M-K3 读了评改却漏掉"固定机位没用全能型"和改法优先级（50%）；M-K1 「总结.md」这个泛标题从没被命中，只靠数据版答 |
| ②语义题 | **词不对就找不到**：本地检索是 unigram+bigram 关键词匹配，问题用词与文档用词不重合时整篇落空，模型转而拿相近文档硬答，引用正确率只有 41% | J-S2 问"公开平台找想签约的博主"，三次检索用了「找博主 签约 / 达人 招募 / 星图 招募」，《公域营销行动指南》一次都没出现，最后拿《2025年终复盘【签约部】》答了一版 0% 覆盖；M-S5「潜水不动手」找不到《社群VIP》；J-S4「带团队修炼自己」找不到《管理者的素养》 |
| ③跨文档汇总题 | **只检索一次、读前 1-3 篇就作答**：全命中率只有 40%。命中列表只给前 6 条，第 3、4 份相关文档被排名挤出去（标题里就含关键词的《人力编制测算模型》排在绩效档案后面），模型也很少换词再搜 | M-X3 一次检索 20 条命中、读 3 篇，《金字塔达人孵化方案》《三层漏斗模型》都没进前 6；J-X5 读了 3 篇，编制模型与会议纪要都没到面前，覆盖 13%；J-X2 读一张总表就答，商务总表与编制模型没碰 |
| ④敏感区题 | **本地路径没有短板**：10/10 全命中、全读到，与关键词题同水平。丢分同样在生成层：大表里挑了另一套口径的数字 | M-P5 读对了《人效核算-2026》，却把"日记账口径 528 万"当收入主数，题目要的"销售额口径 717.6 万"只作括注；M-P4 报了三档目标、漏了达人数 |
| ⑤陷阱题 | 全部敢说没有，但**代价高**：中位 74s、每题 ¥0.23，3 次检索 + 3-5 次 Grep 才敢下结论；说完"没有"再顺带列一堆相近数据 | T-1 珀莱雅：确认没有后附了 9 个年框品牌的 GMV 表；T-2 引用了 Grep 里看到、没 Read 过的《作业评改灰太太》，被产品标为存疑 |

**最差的一类是跨文档汇总题**（全命中 40%、要点覆盖 55%、核心覆盖 57%，三项都是最低），语义题紧随其后（召回 70%、引用正确率 41% 最低）。

## 3. 最差题型失败在哪一层

### 检索层（文件根本没到模型面前）

1. **J-S2**「怎么在公开平台上找到更多想签约的博主？」应命中《公域营销行动指南》。三次检索「找博主 签约」→0 条、「达人 招募」→11 条（全是工资表/执行表）、「星图 招募」→4 条；Grep「招募」→11 处也不含它。文档里说的是「公域营销 / 获客 / 建联 / 私信」，与问题用词零重合。模型最后拿《2025年终复盘【签约部】》和《签约宣讲会线上直播sop》写了一篇像模像样的回答，4 条要点全 missing、2 条引用全落在应命中集合外——**检索层失败，生成层把错料写得很自信**，是最危险的形态
2. **J-X5**「2026 年人力编制和人效怎么规划、年中人力复盘发现了什么？」应命中 3 份。一次检索「人力 编制 人效」→10 条，《2026-OMG人力编制测算模型》标题里三个词全有，却没进前 6（前 6 里有两份绩效考核档案）；模型读了另 3 篇（其中 2 篇不在应命中集合）就作答，编制数字与年中复盘的人效数据全部缺失，覆盖 13%。**排名把标题命中排到正文高频词后面**，加上模型不换词再搜，两个因素叠加

### 生成层（文件读到了，答案没写对/没写全）

1. **M-P5**「2026 年上半年公司的收入、毛利和净利润分别是多少？」读的就是《人效核算-2026》，表头第一行「收入 各部门销售额 上半年合计 7,175,900.90」在眼前，回答却把「日记账口径 528.32 万」放在收入主位，717.59 万只作括注；工资总额那条完全没提。3 条 partial + 1 条 missing，检索层 100% 命中
2. **M-K3**「灰太太 pink bear 丰唇蜜那条视频的核心问题是什么？」唯一应命中文件被读到，回答把"文案画面脱节 / 美颜假发"两条写得很准，但整篇评改的第三条致命问题（固定机位、一个全能型手法都没用）和按优先级的四步改法一字未提——**回答在文档中段就收尾了**。同类还有 M-K5、J-K5：读到即止，只答字面

## 4. 判分与尺子本身的注意事项

- **判分偏保守、要点偏宽**：40 道正题里 26 道是"读对了文件但覆盖率 <75%"，其中多数是答案只回答了问题字面、没带出要点 3-4。这是尺子的设计取向（要点 = "回答这个问题该讲全的事实"），所以同时报核心要点覆盖率。改题时**不许为了迎合当前实现把要点删短**
- **判分模型的 `fabricated` 只用于陷阱题**：正题里多讲一句库内真事也会被标 true。首轮 T-5 就被误判（说了没有专利、顺带讲了商标注册被标编造），已把"标注了来源的相近事实不算编造"写进判分提示词后重判为通过
- **判分要给足 max_tokens**：deepseek-v4-pro 在 Anthropic 兼容端点上先吐推理块，1800 会在推理里耗光、正文为空。首轮 32/45 判分失败，改成 8000 后 `--rejudge --rejudge-failed` 补判 32 题全部成功，回答本身没有重跑
- **Maggie 复刻库已清**，用 `~/Documents/AI/maggie-vault`（同一批源数据、带完整派生层：达人卡/产品页/概念）替代；Jerry 预检库也已清，按单子用 `Downloads/我的知识库`。两库运行时都是 rsync 副本（排除 `.git`/`_assets`），原库零写入
- **产品的引用校验（B-6）不认 Grep**：T-2 引用了 Grep 输出里看到但没 Read 的文件，被标"存疑"——引用其实是对的。这是校验口径的盲区，不是回答的错，先记下，不在本单改
- 一轮成本：对话 ¥10.11（预估 ¥9，超 12%；单题 ¥0.16–0.44，跨文档与陷阱最贵）＋ 判分 ¥2.08（含首轮失败的 ¥0.20）；墙钟 63 分钟（判分每次 50–70 秒是大头）

## 5. 复现与下一步

```bash
cd desktop
npm run bench:retrieval -- --dry-run     # 题数与预算
npm run bench:retrieval                   # 全量一轮 ≈ ¥12，约 65 分钟
npm run bench:retrieval -- --from e2e/retrieval-bench/runs/baseline-0.1.3/results.jsonl   # 只重汇总本基线
```

改检索/提示词之后跑一轮，对着第 1 节的表比。按本基线的失败分布，杠杆从大到小：
1. 语义题的词汇鸿沟——检索侧加同义扩展或标题/摘要字段的语义匹配（云端语义检索本就为此，见 HANDOFF §3-13 的修复单），能直接抬 J-S2 / M-S5 / J-S4 这类 0 命中
2. 跨文档题的"一次检索就作答"——提示词让模型对汇总类问题至少换词再搜一次、把命中列表从 6 条放宽或把标题命中提权（《人力编制测算模型》排不进前 6 是排名问题）
3. 生成层的"读到即止"——关键词/敏感题检索都对了，差在答得短、挑错口径；这是提示词层的活（"回答问题后把文档里紧邻的条件/机制带上"），改完用核心覆盖率与全量覆盖率的差值看效果
